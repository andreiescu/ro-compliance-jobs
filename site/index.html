Connect this browser

Your "applied" list is saved in the GitHub repo so it's the same on every device. This browser needs a GitHub access token once; it's stored only in this browser.

  1. The repo owner opens this pre-filled token page.
  2. Under Repository access, choose Only select repositories → ro-compliance-jobs. Permissions: Contents: Read and write (already filled in).
  3. Click Generate token, copy it and paste it here.
